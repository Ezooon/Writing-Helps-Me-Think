# What has happened so far?

By now, I’ve finished designing the backend and the frontend, and I'm working on the API. Everything is simple, so I can deploy an MVP as soon as possible, but I still made sure it will scale well.

## Week #1: Planning and Learning

I already knew how I’d build the backend, but due to my frontend skills lacking, I decided not to write any code until I understood how they work together.

But I took that time while I was still getting familiar with the frontend to plan everything. I started with the user flow and drew some basic wireframes on paper to help myself imagine the data I’ll need to store and what the users will expect. I then made an ER diagram and a database schema.

About the frontend, I jumped into it only knowing basic HTML and practically no JavaScript or CSS, so I started learning with these 4-hour tutorials, and followed them with another React tutorial. The guy in the tutorial also sold me on TypeScript, so I started learning it as well.

## Week #2

Well, being in university isn’t Ideal, while working on a big project, but I managed to be satisfied with what I learned about frontends, and practiced a little.

I had to quickly review Django, and then I started coding. In no time, I set up an app for the user, demographics, concerns, and their models.

I also installed Django Rest Framework to start building the api as well, but I realized I’m not sure how I want my endpoints to look and return, so I left it until I had finished the frontend.

## Week #3 & #4

I was mainly focused on the frontend for these entire two weeks, and I finally know what the fuss around centering a div is about. It’s not my first time building a UI; I've built many apps using Kivy. It was frustrating at the start, but it got easier and more intuitive the more I used it, and so did React.

This logo is an overly simplified version of that idea, where the superset (outer circle) includes everyone, the blue set is us, and the red one is them, with the middle gradient one including both us, them, and those neither us nor them.
